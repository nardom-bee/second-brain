# second-brain
Este é um primeiro modelo de IA feito por Rodrigo.
Esta IA contém dados sobre ciberseguranca e Inteligencia Artificial e tem como objetivo auxiliar de forma facil quem está comecando na area.
A função dele,além de auxiliar no aprendizado e na carreira, é ser um companheiro na sua trajetória, cada vez enriquecendo mais o conhecimento.
As fontes usadas foram alguns relatórios, entrevistas com CEOs da area e fundamentos alem de toda a base de cibersegurança e vulnerabilidades.
Segue abaixo os conteudos fornecidos por ela tais como as referencias usadas.
